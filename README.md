Practical 1: Kotlin Programming Concepts

1. Practical Title

Develop a Kotlin program for demonstrating various programming
concepts.

2. Objective

The objective of this practical is to understand the basic programming
concepts of Kotlin by implementing different programs. The practical
covers variables and data types, type conversion, user input, control
statements, functions, recursion, arrays, ArrayList, classes,
constructors, operator overloading, and matrix operations.

3. Software Requirements

Programming Language: Kotlin

IDE: IntelliJ IDEA

Platform: Kotlin/JVM

JDK: Java Development Kit (JDK)

4. Practical Programs

1.1 Store and Display Values in Different Variables

Create variables using different Kotlin data types and display their
values.

Data types demonstrated:

Int

Double

Float

Long

Short

Byte

Char

Boolean

String

1.2 Type Conversion

Demonstrate conversion between different data types.

Conversions include:

Integer to Double

String to Integer

String to Double

Kotlin conversion functions such as toDouble() and toInt() are used.

1.3 Scan Student Information and Display All the Data

Take student information as input from the user and display the entered
information.

The program can include:

Student Name

Enrollment Number

Branch

Semester

Other required details

This program demonstrates user input and output in Kotlin.

1.4 Check Odd or Even Numbers

Determine whether a given number is odd or even using the modulo
operator and conditional expression.

Example:

Enter number: 10
10 is Even

1.5 Display Month Name

Use the Kotlin when expression to display the name of a month
according to the number entered by the user.

Example:

Enter month number: 5
May

1.6 User-Defined Function

Create a user-defined function to perform arithmetic operations on two
numbers.

Operations include:

Addition

Subtraction

Multiplication

Division

This program demonstrates function declaration, parameters, return
values, and function calls.

1.7 Factorial Calculation Using Recursion

Calculate the factorial of a number using a recursive function.

Example:

5! = 5 × 4 × 3 × 2 × 1
5! = 120

The function repeatedly calls itself until the base condition is
reached.

1.8 Working with Arrays

Demonstrate different array operations and loop structures in Kotlin.

Topics covered:

Arrays.deepToString()

contentDeepToString()

IntArray.joinToString()

Range using ..

downTo

until

Array traversal

Sorting without using built-in functions

Sorting using built-in functions

1.9 Find Maximum Number from ArrayList

Create an ArrayList of integers and find the maximum number stored in
it.

This program demonstrates:

Creating an ArrayList

Adding elements

Accessing elements

Using loops

Comparing values

Finding the maximum value

1.10 Class and Constructor Creation

Create a Car class with properties such as:

Type

Model

Price

Owner

Miles Driven

The program demonstrates:

Class creation

Constructor

Object creation

Member functions

Displaying object information

Getting the original car price

Calculating the current car price

1.11 Operator Overloading and Matrix Operations

Create a Matrix class and perform matrix operations using operator
overloading.

Operations include:

Matrix Addition

Matrix Subtraction

Matrix Multiplication

The toString() function is also overloaded to display the matrix in a
customized format.

This program demonstrates how Kotlin operators such as +, -, and *
can be overloaded for user-defined classes.

6. How to Run the Programs

Open the project in IntelliJ IDEA.

Open the src folder from the Project panel.

Open the required .kt file.

Click the Run button or right-click the file and select Run.

If the program requires input, enter the values in the Run/Console
window.

Check the output displayed in the console.

Take input from the user.

Use conditional statements and when.

Create and use user-defined functions.

Understand recursion.

Work with arrays and ArrayList.

Use different types of loops.

Create classes, constructors, and objects.

Implement member functions.

Develop and execute Kotlin programs using IntelliJ IDEA.

8. Conclusion

Practical 1 provides a foundation in Kotlin programming by implementing
a series of programs based on fundamental programming and
object-oriented concepts. The practical helps in understanding how
Kotlin handles variables, input, control flow, functions, recursion,
collections, classes, and operator overloading. These concepts form an
important foundation for further Kotlin and Android application
development.
